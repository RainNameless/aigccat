## 建议阅读顺序

1. **想跑起来** → 先看根目录 `README.md` 的「快速开始」，再按 `DEPLOYMENT.md` 配置
2. **想让它真的生成模型** → `STUDIO-SESSION.md`，接入你自己的网页订阅会话
3. **想改代码** → `UI.md` 的第 8 节（改前端的硬性约定）是最容易踩坑的地方
4. **想让 AI 帮你生产资产** → `MCP.md`，不需要任何生成服务的 Key

改动的历史原因可通过 git 提交历史与 Release 说明查看。
